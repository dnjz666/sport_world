## 真机结果与未消除的恢复偏差

设备、系统及工具与 M0 相同：SGT-AL50、HarmonyOS 7.0.0.109、testhelper 1.0.1、USB HDC 服务 127.0.0.1:8710。用户解锁并保持读取页前台；复验脚本主动关闭模拟并核对成功后，再建立读取边界和采集基线。完整脱敏数据见[任务 5 证据](evidence/2026-10-17-task5-executor-device.json)。

| 试验 | 结果 |
| --- | --- |
| 完整两点复验基线 | 5 个新回调，样本间距在预定 10 米范围内 |
| 固定点 | 两点相距 133.434 米；每点 6 次单点 GPX 下发、5 个判定窗口内的独立样本；最大误差约 0.000326 米，满足原定 5 米判据 |
| 完整两点试验停止 | 关闭与文件清理成功；13 个新回调距原基线约 51.027–84.207 米，未达到原定 50 米恢复半径，因此本次恢复不通过 |
| 独立 USB 恢复复核 | 用户确认手机静止；另采 5 个新稳定基线样本，单固定点取得 5 个独立样本、最大误差约 0.000583 米；finally 关闭后 3 个新正常样本距本次基线 0 米，时间差绝对值 244 毫秒，满足原定恢复判据 |
| 最终资源清理 | 以上两次有效试验的 18 个 GPX、22 个 UI 文件按摘要清理；4 个专属远端目录均只在空时删除并另行确认不存在，执行器本机临时目录也已不存在 |

亚毫米差异仅表示模拟坐标与回调数字接近，不代表真实 GNSS 物理精度。恢复仍要求至少 3 个新样本、时间差绝对值不大于 5 秒、精度不大于 50 米、距本次正常基线不大于 50 米且距测试点至少 100 米，判据没有放宽。

约 51 米偏差原因未明，用户报告手机未移动；独立复核的通过不覆盖原会话的失败。读取器暴露的是来源数值文本，不能据此自行解释为某个坐标系或定位提供器的问题。更早的首轮诊断没有主动预关闭模拟，虽取得两点与恢复样本，也不计入最终验收；原始记录仍保留。

## 操作与接续

可复现入口见[桌面说明](../../desktop/README.md)及[手动验收脚本](../../desktop/scripts/verify-executor-device.mjs)。默认需要显式 `--run-device-check` 才会操作手机；`--recovery-only` 仅运行一次新基线下的单固定点／停止恢复，并明确记录独立复核范围，不能替代两点验收。

本轮沿用已有读取 HAP，没有新增手机定位执行程序、修改签名或申请系统模拟权限。普通测试不访问手机；原始命令、位置、GPX 输入判据和 UI 文件位于忽略的 local-data，脱敏证据保存这些文件的摘要，不公开精确位置或完整目标 ID。

任务 6 必须实现会话状态、停止后的独立恢复判定和日志：stop.accepted 仅表示工具关闭及本实例资源清理被接受，不能直接标为正常定位恢复；原会话恢复不达标应保留 recovery_required，不能用另一个基线的通过替代。完整 USB 会话、断线、运动世界兼容和脱机仍待相应任务验证，verifiedStandalone 保持 false。
