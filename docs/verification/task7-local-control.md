## 交付

[server.ts](../../desktop/src/server.ts) 只监听 127.0.0.1 的系统分配端口，提供 GET /api/state、GET /api/targets、POST /api/session；指令、快照沿用任务 6。服务核对精确 Host／Origin，POST 限定 JSON 与 256 KiB，固定静态资源白名单，未提供任意命令或文件读取入口。损坏请求不会修改会话。250 毫秒调度持续驱动运行、暂停和恢复待确认状态，实际样本间隔仍由配置及执行耗时约束。

[index.ts](../../desktop/src/index.ts) 装配真实 HDC、能力报告、执行器、独立读取、Replay、控制器及 JSONL 日志。默认读取项目 docs/verification/m0-report.json，可用 M0_REPORT_PATH 覆盖；HDC_PATH 可覆盖默认工具路径。报告缺失或失效时保留能力未确认，不提供合成数据回退。日志保存到忽略的 local-data/sessions/。

[控制界面](../../desktop/web/index.html) 提供显式设备选择、名称与坐标编辑／JSON 导入、闭合形状及距离／用时预览、配速／圈数／方向、开始／暂停／继续／停止。预期、已提交及独立读取坐标分别显示，未知来源与模拟标记保留未知；恢复待确认单独提示。损坏输入和无效导入保留原编辑值；掉线保留原设备选择。服务连接失败后明确显示当前状态未知，旧数值标为最后一次读取。

页面将已应用配置绑定 sessionId，并携带可选 X-Session-Id，服务端在派发前同步检查。另一标签页替换配置时，旧页面不能启动新路线；紧急停止不受旧标识阻止。每次会话结束后需重新应用配置。刷新活动页面只显示当前圈，避免将表单默认圈数误作活动会话总圈数。

Ctrl+C／SIGTERM 先关闭 HTTP 和调度，再尝试停止并独立核对恢复，退出等待上限 60 秒。关闭被接受、超时或失败不能替代正常观测。createControlServer.close 只关闭服务资源，createApplication.close 负责设备停止与恢复等待；重复调用共用关闭流程。使用说明见[桌面说明](../../desktop/README.md)。
